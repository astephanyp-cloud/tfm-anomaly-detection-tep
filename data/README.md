# Data

The raw Tennessee Eastman Process dataset is **not redistributed** in this repository.

Use the public multi-run dataset cited in the thesis:

Rieth, C. A., Amsel, B. D., Tran, R., & Cook, M. B. (2017). *Additional Tennessee Eastman Process Simulation Data for Anomaly Detection Evaluation*. Harvard Dataverse.

DOI: https://doi.org/10.7910/DVN/6C3JR1

The analysis uses 52 process variables (41 XMEAS + 11 XMV). Identifier columns such as `faultNumber`, `simulationRun` and `sample` are used for grouping and evaluation but not as model predictors.
